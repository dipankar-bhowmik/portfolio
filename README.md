# Dipankar Bhowmik — Sysadmin & DevOps Control Room

Interactive, zero-dependency portfolio web application for **Dipankar Bhowmik** (`IT Support Engineer | Linux & Network Administration`).

## Files Included
- `index.html` (Modular HTML5 markup + UI controller)
- `styles.css` (Dark Control Room & High-Contrast Light Mode stylesheet)
- `lib.js` (Closed-world ground truth data, Ansible patch pipeline simulation engine, 3 Helpdesk triage state machines, CLI parser, CIDR & `chmod` utilities)
- `index.bundled.html` (Single-file zero-dependency standalone build)
